# Antons Blocked Drains Hawkesbury

Fast static Astro website for `https://blockeddrainshawkesbury.com.au`.

## Local development

Run `npm install`, then `npm run dev`. Run `npm run build` before release; the build checks metadata, internal links, schema, FAQs and Australian English.

## Deployment

The project is prepared for a Git-connected Cloudflare static deployment. Production is indexable by default. Set `PUBLIC_ALLOW_INDEXING=false` only for a staging build. Configure the `www` hostname to redirect permanently to the non-`www` canonical domain while preserving paths and query strings.
